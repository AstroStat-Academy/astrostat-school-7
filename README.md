# AstroStat School 2026 — Rome

This repository contains the lecture materials for the **7th AstroStatistics School**, Rome 2026.

The book is published at: [astrostat-academy.github.io/astrostat-school-7](https://astrostat-academy.github.io/astrostat-school-7/)


## Instructions for contributors

- Add your folder to the repo
- Add the relative path to the notebook in `_toc.yml`
- Add the **static paths** to the `data` adn `images` sub-folders  in the `_config.yml`
- Add a short description of your notebook in `index.md`
